Common Questions

Does this version read my PDF?

This version demonstrates the frontend only. PDF selection works, but the file is not parsed or sent anywhere. Questions are clearly labeled samples.

Can I download a question paper and answer key separately?

Yes. Each export opens a print window. Choose Save as PDF to save that document.

Where are my papers and attempts saved?

In this browser’s local storage. They will not sync between devices, and clearing browser data removes them.

How do I skip a question?

Press Next without selecting an answer. Use the numbered question buttons to return at any time before submission.

Can I reduce the animation?

Use Settings to turn transitions off. Your system’s reduced-motion preference is also respected.
